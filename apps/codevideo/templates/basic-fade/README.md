# CodeVideo Basic Fade Template

A simple CodeVideo project that demonstrates basic text fade-in animation.

## Getting Started

```bash
# Install dependencies
npm install

# Start development studio
npm run studio

# Visit http://localhost:3000 to see your video
```

## The Animation

This template shows:
- Basic `useFrame()` hook usage
- Simple `interpolate()` function for fade effects
- Clean component structure
