## 🚀 **How to Use CodeVideo**

### **Quick Start**
```bash
# Create new project
npx create-codevideo my-video

# Start development
cd my-video
npm install
npm run dev

# Open http://localhost:3000
```

### **Daily Workflow**
```bash
# Launch studio
npm run studio

# Edit code in browser
# Use AI for enhancements
# Render final video
npm run render src/MyVideo.tsx output/video.mp4
```

### **CLI Usage**
```bash
# Render video
codevideo render src/MyVideo.tsx output/video.mp4

# Enhance code with AI
codevideo enhance src/MyVideo.tsx --enhancement "add particles"

# Get suggestions
codevideo suggest src/MyVideo.tsx
```
